# 掌中星轨 · His Orbit

每个角色都有自己的轨道 ✨

## 🌌 简介
掌中星轨是一个藏在手机里的迷你世界。
你的手机里住着一群有自己轨道的角色。
他们会发朋友圈、给你发短信、打电话、吃醋、想念、靠近或远离。

## 📱 功能
- 手机桌面：时钟、信号、电量，模拟真实手机
- 备忘录 & 待办：日常记录
- 手机管家 Smart：极聪明的管家意识体
- 角色聊天：和角色真实对话
- 朋友圈：每个角色每天动态更新
- 调色：跟 Smart 说你想换风格
- 番茄钟、心情记录等小工具

## 🚀 使用
直接打开 index.html 即可使用。
需要配置 API Key 才能启用角色聊天和 Smart 管家。
